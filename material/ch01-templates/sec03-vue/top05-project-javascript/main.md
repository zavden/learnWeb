# Vue Project JavaScript

Use this template when the lesson should feel like a small Vue project stored inside one Markdown document.

## Format

- `framework: vue`
- `mode: multi-file`
- JavaScript files plus `HTML` render files and CSS

## Expected structure

- one entry file such as `src/main.js`
- one app file
- supporting components and composables in separate files
- `HTML` render files imported explicitly where needed

## When to use it

- for teaching component composition and event flow
- for showing how Vue multi-file structure works without SFC syntax

## Limitations

- templates are imported as virtual `HTML` render modules
- this is not yet the same thing as authoring every component as `.vue`
