# HTML + TypeScript

Use this template when the lesson needs DOM scripting with types but without extra CSS complexity.

## Blocks

- `HTML`
- `TypeScript`

## When to use it

- for typed DOM queries and event handlers
- for showing how TypeScript transpiles before runtime

## Notes

- TypeScript currently runs in transpile-only mode for the preview pipeline
- if the lesson also needs styles, later topics can combine this idea with CSS or SCSS examples
