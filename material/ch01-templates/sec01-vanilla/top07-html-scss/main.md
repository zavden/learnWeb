# HTML + SCSS

Use this template when the lesson needs HTML plus nested styles, variables or other SCSS features.

## Blocks

- `HTML`
- `SCSS`

## When to use it

- for design-system oriented examples
- for teaching nesting, variables and structure in stylesheets

## Notes

- SCSS is compiled before the preview renders
- keep the example inline; imports between SCSS files are not the focus of this template chapter
