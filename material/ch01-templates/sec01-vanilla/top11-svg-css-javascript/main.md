# SVG + CSS + JavaScript

Use this template when the lesson needs interactive SVG behavior with styled vector graphics.

## Blocks

- `SVG`
- `CSS`
- `JavaScript`

## When to use it

- for click, hover, animation triggers and DOM manipulation over SVG nodes
- for debugging interaction order with the console

## Notes

- this is the most complete vanilla SVG teaching mode currently covered by presets
- use it when visual response and event handling matter together
