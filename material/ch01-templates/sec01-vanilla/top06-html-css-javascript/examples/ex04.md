# JavaScript

```javascript
let value = 0;
const output = document.getElementById('value');

document.querySelectorAll('.stepper').forEach((button) => {
  button.addEventListener('click', () => {
    value += Number(button.dataset.step);
    output.textContent = String(value);
  });
});
```
