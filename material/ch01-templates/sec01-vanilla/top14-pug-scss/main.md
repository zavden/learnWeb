# Pug + SCSS

Use this template when the lesson combines compiled markup and compiled styles in the same example.

## Blocks

- `Pug`
- `SCSS`

## When to use it

- for showing a compact authoring workflow without plain HTML or plain CSS
- for intermediate lessons where both compile steps matter

## Notes

- both blocks compile before runtime
- this format is useful when you want to compare authoring syntax against rendered output
