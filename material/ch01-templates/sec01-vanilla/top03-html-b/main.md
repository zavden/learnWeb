# HTML-B

Use this template when you want to teach explicitly that the markup block represents only the page body.

## Blocks

- `HTML-B`

## When to use it

- when the distinction between body fragment and full document matters
- when teaching how this app injects the preview shell automatically

## Notes

- `HTML-B` is a pedagogical alias of `HTML`
- both compile to the same body-fragment behavior in the renderer
