# React Single-File TSX

Use this template when the lesson should introduce React with TypeScript syntax in one file.

## Blocks

- `TSX`

## Expected structure

- one top-level `App` component in TSX
- local types or simple typed state inside the same block

## When to use it

- for typed props, typed state and generic React patterns
- for showing how TSX changes authoring without adding project structure

## Limitations

- this mode stays single-file on purpose
- it is best for focused syntax and typing lessons, not for multi-file architecture
