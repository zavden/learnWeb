# React Project + JSON

Use this template when the lesson needs a small React project that imports structured local data.

## Format

- `framework: react`
- `mode: multi-file`
- JSX files plus local `JSON`

## Expected structure

- one entry file
- one app file
- one or more JSON files for small datasets or configuration

## When to use it

- for teaching static data flow into components
- for exercises that should feel closer to a small app than to a single widget

## Limitations

- JSON is supported as structured local data inside the Markdown project
- binary assets are still handled through the topic-level `assets/` folder rather than as virtual files
