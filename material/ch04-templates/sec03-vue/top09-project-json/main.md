# Vue Project + JSON

Use this template when the lesson needs local structured data inside a Vue project stored in one Markdown file.

## Format

- `framework: vue`
- `mode: multi-file`
- `.vue` or project files plus local `JSON`

## Expected structure

- one entry file
- one app file or `.vue` root component
- one or more JSON files used as local data sources

## When to use it

- for teaching static data flow into Vue templates and components
- for small app-like examples that need more than hard-coded arrays

## Limitations

- JSON is supported as virtual structured data
- binary assets still belong in the topic-level `assets/` folder instead of virtual file blocks
