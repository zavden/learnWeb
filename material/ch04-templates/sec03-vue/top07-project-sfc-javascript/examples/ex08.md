## @file src/App.vue
## @lang vue
## @role app

```vue
<template>
  <main class="choice-shell">
    <h1>Emit from a child SFC</h1>
    <p>Current choice: {{ currentChoice }}</p>
    <div class="choice-row">
      <ChoiceButton label="Template" @pick="setChoice" />
      <ChoiceButton label="Composable" @pick="setChoice" />
      <ChoiceButton label="Store" @pick="setChoice" />
    </div>
  </main>
</template>

<script setup>
import { ref } from 'vue';
import ChoiceButton from './components/ChoiceButton.vue';

const currentChoice = ref('Template');

function setChoice(label) {
  currentChoice.value = label;
}
</script>
```

## @file src/components/ChoiceButton.vue
## @lang vue
## @role component

```vue
<template>
  <button type="button" @click="emit('pick', label)">{{ label }}</button>
</template>

<script setup>
const props = defineProps({
  label: {
    type: String,
    required: true,
  },
});

const emit = defineEmits(['pick']);
const label = props.label;
</script>
```
