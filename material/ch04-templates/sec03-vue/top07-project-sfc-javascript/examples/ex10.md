```vue
<template>
  <main class="util-shell">
    <h1>{{ formatLessonName('utility modules') }}</h1>
    <ul>
      <li v-for="lesson in lessons" :key="lesson">{{ formatLessonName(lesson) }}</li>
    </ul>
  </main>
</template>

<script setup>
import { formatLessonName } from './utils/formatLessonName.js';

</script>
```

## @file src/utils/formatLessonName.js
## @lang javascript
## @role util

```javascript
export function formatLessonName(value) {
  return value
    .split(' ')
    .map((part) => part.charAt(0).toUpperCase() + part.slice(1))
    .join(' ');
}
```
