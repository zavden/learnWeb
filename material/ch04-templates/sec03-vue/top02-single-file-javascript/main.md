# Vue Single-File JavaScript

Use this template when the lesson should focus on one Vue component written with Composition API in JavaScript.

## Blocks

- `HTML`
- `JavaScript`

## Expected structure

- the `HTML` block provides the template
- the `JavaScript` block exports a Vue component object
- Composition API inside `setup()` is the preferred teaching style

## When to use it

- for introducing refs, computed values and template bindings
- for very small Vue lessons that should stay inside one example

## Limitations

- this is not a `.vue` SFC file
- local relative imports are not the point of this mode; move to multi-file when file structure matters
