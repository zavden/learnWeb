# Vue Single-File CSS + JavaScript

Use this template when the lesson needs a Vue template, Composition API logic and a dedicated style block.

## Blocks

- `HTML`
- `CSS`
- `JavaScript`

## Expected structure

- a template block
- one CSS block for styling
- one JavaScript block exporting the Vue component

## When to use it

- for reactive UI lessons with visible styling changes
- for teaching Vue event handling without introducing project structure

## Limitations

- this still follows the block-based learning mode, not SFC syntax
- use it for atomic lessons, not for larger component systems
