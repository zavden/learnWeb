# Vue Project TypeScript + SCSS

Use this template when the lesson needs a typed Vue mini-project with project-level SCSS.

## Format

- `framework: vue`
- `mode: multi-file`
- `TypeScript` files
- `HTML` render files
- `SCSS` styles

## Expected structure

- typed entry and app files
- composables or components in separate files
- one shared SCSS stylesheet or a small style set

## When to use it

- for stronger examples around typed Composition API and project organization
- for lessons where style preprocessing is also part of the teaching goal

## Limitations

- Vue still uses explicit render imports from `HTML` files in this mode
- if the lesson should focus on `.vue` authoring, move to the SFC topics
