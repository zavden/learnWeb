# Vue Single-File TypeScript

Use this template when the lesson needs Vue Composition API plus TypeScript in one focused example.

## Blocks

- `HTML`
- `TypeScript`
- optional `CSS`

## Expected structure

- the template lives in `HTML`
- the component logic is exported from `TypeScript`
- `defineComponent(...)` or typed Composition API patterns fit well here

## When to use it

- for typed refs, typed props-like structures and computed values
- for bridging from JavaScript Vue lessons to typed authoring

## Limitations

- this mode remains block-based and intentionally small
- if the lesson needs multiple files or SFC syntax, use one of the project templates instead
