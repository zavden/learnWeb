# JavaScript

```javascript
const runner = document.getElementById('runner');
let angle = 0;

setInterval(() => {
  angle += 0.12;
  const x = 120 + Math.cos(angle) * 48;
  const y = 70 + Math.sin(angle) * 48;
  runner?.setAttribute('cx', String(x));
  runner?.setAttribute('cy', String(y));
  console.info('runner-angle', angle.toFixed(2));
}, 500);
```
