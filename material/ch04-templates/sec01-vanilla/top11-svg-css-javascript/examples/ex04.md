# JavaScript

```javascript
const kite = document.getElementById('kite');
let rotated = false;

kite?.addEventListener('click', () => {
  rotated = !rotated;
  kite.style.transform = rotated ? 'rotate(45deg)' : 'rotate(0deg)';
});
```
