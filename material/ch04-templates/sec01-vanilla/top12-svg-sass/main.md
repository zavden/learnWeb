# SVG + SASS

Use this template when the lesson needs indented SASS syntax on top of SVG markup.

## Blocks

- `SVG`
- `SASS`

## When to use it

- for teaching the SASS syntax variant instead of SCSS
- for compact style demos around SVG shapes and states

## Notes

- this differs from `SVG + CSS` only in the style language and compile step
- it is useful when the syntax itself is part of the lesson
