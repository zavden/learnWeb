# HTML

Use this template when you only need raw markup and the app can wrap it inside the preview document automatically.

## Blocks

- `HTML`

## When to use it

- for the smallest possible DOM example
- for semantic markup exercises
- for layout sketches before adding styles or scripts

## Notes

- the `HTML` block is treated as body content, not as a full document
- if you need a complete document with `<!DOCTYPE html>`, use `HTML-FULL`
