# SCSS

```scss
$accent: #2563eb;
$surface: #ffffff;

body {
  margin: 0;
  min-height: 100vh;
  display: grid;
  place-items: center;
  background: linear-gradient(180deg, #eff6ff, #dbeafe);
  font-family: system-ui, sans-serif;
}

.hero-card {
  display: grid;
  gap: 10px;
  max-width: 360px;
  padding: 24px;
  border-radius: 20px;
  background: $surface;
  color: #1e3a8a;

  h1,
  p {
    margin: 0;
  }

  .eyebrow {
    font-size: 12px;
    letter-spacing: 0.08em;
    text-transform: uppercase;
    color: $accent;
  }
}
```
