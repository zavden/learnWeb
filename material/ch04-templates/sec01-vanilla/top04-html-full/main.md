# HTML-FULL

Use this template when the lesson needs a complete HTML document with its own `<head>`, inline `<style>` tags or inline `<script>` tags.

## Blocks

- `HTML-FULL`

## When to use it

- when you need full control over document structure
- when you want to teach `meta`, `title`, inline script order or document-level setup

## Notes

- `HTML-FULL` is not combined with separate `CSS` or `JavaScript` blocks
- this mode is closer to a standalone `.html` file than to the normal body-fragment flow
