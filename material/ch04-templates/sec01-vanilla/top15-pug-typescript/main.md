# Pug + TypeScript

Use this template when the lesson needs compiled markup plus typed browser logic.

## Blocks

- `Pug`
- `TypeScript`

## When to use it

- for interactive template demos where typing helps the script side
- for lessons that compare authoring compilers on both markup and logic

## Notes

- Pug compiles to HTML first and TypeScript transpiles before execution
- this is a good bridge between template syntax and typed DOM scripting
