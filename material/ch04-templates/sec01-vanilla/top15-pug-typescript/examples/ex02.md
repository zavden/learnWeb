# Pug

```pug
label
  | Search
  input#search-box(type="text" placeholder="Type a query")
p#mirror Start typing...
```

# TypeScript

```typescript
const input = document.getElementById('search-box') as HTMLInputElement | null;
const mirror = document.getElementById('mirror') as HTMLParagraphElement | null;

input?.addEventListener('input', () => {
  if (mirror) {
    mirror.textContent = input.value ? `Searching for: ${input.value}` : 'Start typing...';
  }
});
```
