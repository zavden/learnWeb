# HTML + CSS + JavaScript

Use this template when the lesson needs markup, styling and browser behavior together.

## Blocks

- `HTML`
- `CSS`
- `JavaScript`

## When to use it

- for DOM events, interactivity and state without TypeScript
- for stepping through execution order with the runtime console

## Notes

- this is the classic three-panel vanilla workflow
- it is a good default when you need the full frontend loop but not extra compilers
