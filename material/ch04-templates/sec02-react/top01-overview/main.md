# React Templates Overview

This topic is the entry point for the `Templates / React` section.

It will document the React variants currently supported by the app, including:

- `single-file` React examples

Later phases will expand this section into concrete template topics and curated examples.

For now, this topic provides a stable place to organize the React template map.
