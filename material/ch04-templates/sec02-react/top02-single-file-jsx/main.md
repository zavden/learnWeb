# React Single-File JSX

Use this template when the lesson should focus on one React component written in plain JSX.

## Blocks

- `JSX`

## Expected structure

- a single top-level `App` component in the JSX block
- no extra HTML block, because the app mounts React automatically

## When to use it

- for the first contact with components, props-like thinking and local state
- for tiny hook exercises that should stay inside one editor file

## Limitations

- this mode is intentionally minimal and expects a single-file component flow
- the runtime is educational, not a full project scaffold with arbitrary imports
