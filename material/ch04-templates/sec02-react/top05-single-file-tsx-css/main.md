# React Single-File TSX + CSS

Use this template when the lesson needs typed React code plus local styling.

## Blocks

- `TSX`
- `CSS`

## Expected structure

- one `App` component written in TSX
- one CSS block for the visual layer

## When to use it

- for typed component exercises with visible UI feedback
- for lessons that combine React typing and styling without introducing multi-file imports

## Limitations

- the example still behaves as a single-file learning unit
- if the lesson needs hooks, components or helpers split into files, use a project template instead
