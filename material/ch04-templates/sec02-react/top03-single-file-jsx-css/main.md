# React Single-File JSX + CSS

Use this template when the lesson needs one JSX component plus local styling.

## Blocks

- `JSX`
- `CSS`

## Expected structure

- one `App` component in JSX
- one stylesheet block for component-level or page-level styles

## When to use it

- for visual component exercises
- for teaching how React structure and CSS styling work together without extra files

## Limitations

- styles still live in a separate block; this mode does not try to emulate CSS-in-JS
- keep the example small and atomic instead of turning it into a project
